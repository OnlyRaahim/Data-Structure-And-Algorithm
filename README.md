# 🚀 Learning Philosophy

I am not aiming to simply memorize solutions.

For every problem, I want to understand:

1. **What is the problem asking?**
2. **What approach can solve it?**
3. **Which data structure should I use?**
4. **Why does the algorithm work?**
5. **What is the time complexity?**
6. **What is the space complexity?**
7. **Can the solution be optimized?**

The goal is to become better at **thinking about problems**, not just writing code.
